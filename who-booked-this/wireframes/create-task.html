The explanation box appears on every task creation — not a tooltip, not a help screen. It's present every time because the principle is that important.
The "I'll do this" toggle is off by default. Claiming is an active choice, not the path of least resistance.
The submit button says "Surface this gap" — consistent language. You're doing something useful for the group, not creating work for yourself.
Detail field is optional but prompted. The person who notices a gap often has the most context — this captures it for whoever claims it later.
